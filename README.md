# Product Failure Analysis — Concept Crafters

Workspace for the SPSU CSE Concept Crafters Task 1 product-failure-analysis assignment.

This repository starts with a report structure only. It does not claim that a specific product failed, and it contains no verified findings or real dataset. Fill the template from the assigned case materials before submission.

## Workflow

1. Define the product, failure symptom, time window, and scope from the assigned brief.
2. Preserve the source and date for every observation.
3. Separate facts, assumptions, candidate causes, and confirmed findings.
4. Quantify impact only when the data supports a reproducible calculation.
5. Recommend corrective and preventive actions with measurable verification.

## Files

- [Analysis template](docs/analysis-template.md) — report structure and evidence tables.
- [Data handling notes](data/README.md) — source provenance and privacy guidance.

## Validation checklist

- [ ] The product and failure description match the assigned brief.
- [ ] Every material claim cites its source.
- [ ] Root causes are labeled as hypotheses until confirmed.
- [ ] Sample counts, denominators, dates, and units are recorded.
- [ ] Corrective actions include owners and measurable verification.
- [ ] Limitations and unresolved questions are explicit.

Do not add confidential source data, personal/customer identifiers, credentials, or invented results.
