# Data Handling Notes

- Check assignment instructions and licensing before adding any file to Git.
- Keep source data unchanged and record provenance, collection date, and any processing.
- Do not commit confidential customer details, personal identifiers, credentials, or private reports.
- Use a small sanitized sample when it is necessary and permitted.
- Record schema, units, missing values, exclusions, and transformations.
- No dataset is included in this starter. Leave this directory without data until authorized case material is available.
